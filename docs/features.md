# Features · 功能说明

更新：2026-01-10

## 核心功能

### 提示词创作

**输入与编辑**
- 多行文本输入框，最大 12000 字
- 自动保存草稿到浏览器
- 字数实时统计，接近上限（90%）红色警告
- 支持 Ctrl/⌘ + Enter 快速提交
- 按 `/` 键快速聚焦到提示词框

**快捷模板**
- 4 个内置模板：产品摄影、自然风景、创意海报、场景插画
- 一键填入工作台，填入后可继续修改
- 模板库独立页面，展示完整提示词

**提示词库（片段管理）**
- 选中文字保存为可复用片段
- 6 个分类：场景、光线、风格、构图、材质、其它
- 按分类分组展示
- 插入时自动添加中文分隔符
- 支持重新分类和删除
- LocalStorage 持久化

### 图像生成

**模型与参数**
- 实时读取当前密钥可用模型
- 4 种尺寸：方形（1:1）、横向（3:2）、竖向（2:3）、自动
- 质量选项：服务商默认、低、中、高
- 当前限制一次 1 张（可在 config/studio.json 调整）

**生成流程**
- 本地队列串行生成，不并发
- 状态实时更新：等待 → 生成中 → 已完成
- 生成失败不自动重试
- 支持请求 ID 去重，防止重复提交

**结果预览**
- 实时显示生成状态和进度
- 完成后显示原图预览
- 显示模型、尺寸、耗时、图片数量
- 点击图片放大查看
- 支持键盘左右方向键切换任务

### 作品管理

**历史记录**
- 按时间倒序展示所有任务
- 搜索：按提示词或模型名称过滤
- 状态标记：已完成、失败、中断
- 显示日期、尺寸、状态
- 点击卡片查看详情或回到工作台

**批量操作**
- 复选框批量选择任务
- 全选/取消全选
- 批量下载图片（自动间隔下载）
- 批量导出为 JSON（含完整元数据）
- 批量删除（删除任务和图片文件）
- 删除保护：执行中任务不能删除

**任务操作**
- 复用提示词：回填参数到工作台
- 复制提示词：纯文本复制
- 下载原图：保留原始格式和字节

### 界面与交互

**主题**
- 深色/浅色主题切换
- 跟随系统偏好（首次）
- 浏览器持久化记忆

**响应式布局**
- 桌面：双栏布局（编辑器 + 预览）
- 平板/手机：单栏堆叠
- 小屏隐藏侧边栏细节

**键盘快捷键**
- `/`：聚焦提示词输入框
- Ctrl/⌘ + Enter：提交生成
- 左/右方向键：切换历史任务

**无障碍**
- 跳过链接（键盘导航）
- ARIA 标签和语义化 HTML
- 屏幕阅读器友好

## 安全与隐私

**密钥隔离**
- 密钥只由服务端读取
- 前端永远拿不到 API Key
- 请求使用本地会话 token
- 不暴露远端签名 URL

**本地优先**
- 所有数据保存在电脑上
- 图片保存在 outputs/ 目录
- 任务记录在 .data/jobs/
- 不上传到云端

**同源保护**
- 只允许 127.0.0.1 和 localhost 访问
- POST 请求检查 Origin 和 Host
- 静态文件白名单
- 图片路径严格格式验证

## 技术特性

**零依赖运行**
- 原生 HTTP 服务
- 静态 HTML/CSS/JS
- 不需要 React、Vue 等框架
- 桌面版不需要 Node.js

**数据持久化**
- 任务元数据：JSON 文件
- 原图：按日期分类保存
- 草稿和主题：浏览器 LocalStorage
- 提示词片段：LocalStorage

**错误处理**
- 脱敏错误信息（不泄露密钥）
- 超时警告（可能已计费）
- 失败不自动重试
- 重启后未完成任务标记中断

**并发控制**
- 同目录服务互斥锁
- 单任务串行队列
- 请求 ID 去重
- 队列上限保护
