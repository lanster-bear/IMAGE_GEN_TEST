# User Guide · 使用指南

快速上手和常见问题。

## 快速开始

### 首次启动

1. 确保 `Image_key.txt` 包含有效的 API 密钥
2. 双击 `Image Studio.exe`（桌面版）或运行 `npm start`（开发）
3. 浏览器自动打开 `http://127.0.0.1:13030`

### 第一次生图

1. 在「工作台」输入提示词，例如：
   ```
   一只橙色的猫在阳光下打盹，柔和的自然光，浅景深，真实照片质感
   ```
2. 选择模型（首次自动选第一个）
3. 选择尺寸（默认 1024×1024）
4. 点击「生成图像」
5. 等待生成完成，图片会显示在下方

### 查看历史

1. 点击侧边栏「记录」
2. 所有生成的任务按时间倒序排列
3. 点击任务卡片查看详情或复用提示词

## 核心功能使用

### 提示词编写技巧

**结构建议：**
```
主体描述 + 场景环境 + 光线效果 + 风格要求 + 技术参数
```

**示例：**
```
产品摄影场景：
一瓶高级香水放在大理石台面上，背景是柔和的奶油色渐变，
侧面自然光透过纱窗投射，细腻的玻璃折射，产品居中构图，
保留充足留白，不要文字，真实材质，克制的高级感

自然风景：
金色夕阳下的海边礁石，浪花轻拍岸边，远处帆船剪影，
天空云层染上橙红色，前景礁石细节清晰，中景到远景自然虚化，
16:9 横构图，电影色调，真实摄影质感
```

**提示：**
- 中英文都支持，建议用中文（模型会自动理解）
- 明确说"不要文字"避免图中出现字母
- 描述具体光线和材质提升质量
- 字数上限 12000 字，接近时会红色警告

### 使用提示词库

**保存片段：**
1. 在工作台输入或粘贴提示词
2. 选中要保存的部分（例如"柔和的侧面自然光，细腻的玻璃折射"）
3. 点击「保存片段」按钮
4. 输入名称（如"光线-玻璃折射"）
5. 选择分类（1-场景、2-光线、3-风格、4-构图、5-材质、6-其它）

**组合使用：**
1. 进入「提示词库」页面
2. 找到需要的片段
3. 点击「插入到提示词」
4. 自动跳转到工作台，片段已插入光标位置
5. 重复插入多个片段快速组合提示词
6. 片段间会自动添加中文分隔符

**管理片段：**
- 切换分类：点击片段卡片上的下拉菜单
- 删除片段：点击卡片上的「删除」按钮
- 片段保存在浏览器，不会丢失

**推荐分类：**
- **场景**：室内、户外、工作室、自然环境等
- **光线**：自然光、侧光、逆光、黄金时段、玻璃折射等
- **风格**：真实摄影、插画、电影感、水彩、油画等
- **构图**：居中、三分法、留白、景深、视角等
- **材质**：玻璃、金属、木质、织物、陶瓷等
- **其它**：情绪、色调、技术参数等

### 使用模板

1. 点击侧边栏「模板」
2. 浏览 4 个内置模板
3. 点击「使用此模板」填入工作台
4. 根据需求修改提示词
5. 提交生成

**内置模板：**
- 产品摄影：电商、商业摄影风格
- 自然风景：风光摄影、户外场景
- 创意海报：扁平插画、商业设计
- 场景插画：室内场景、叙事性插画

### 参数预设

在工作台「比例」下方：

1. 选好模型、比例、质量
2. 点「保存当前」，起个名字
3. 下次从下拉框选中，三个参数一起换上，提示词不动
4. 选中后点「删除」去掉这组

预设只存在这台电脑的浏览器里。

### 批量操作

**批量下载图片：**
1. 进入「记录」页面
2. 勾选要下载的任务
3. 点击「下载图片」
4. 浏览器会自动间隔下载所有图片

**批量导出数据：**
1. 勾选要导出的任务
2. 点击「导出 JSON」
3. 获得包含提示词、参数、时间等完整元数据的文件
4. 可用于备份或迁移到其它设备

**批量删除：**
1. 勾选要删除的任务
2. 点击「删除选中」
3. 确认后删除（同时删除任务记录和图片文件）
4. 注意：正在生成的任务不能删除

**快捷操作：**
- 点击「全选」快速选中所有任务
- 再点击「全选」取消选择
- 顶部显示「已选 X 项」

### 复用历史提示词

**方法一：回填工作台**
1. 在「记录」点击任务卡片
2. 自动跳转到工作台
3. 提示词和参数自动填入
4. 可继续修改后重新生成

**方法二：纯文本复制**
1. 点击任务卡片进入详情
2. 点击「复制提示词」
3. 粘贴到其它地方使用

### 主题切换

1. 点击右上角「主题」按钮
2. 切换深色/浅色模式
3. 设置会自动保存到浏览器

## 快捷键

| 按键 | 功能 |
|------|------|
| `/` | 聚焦到提示词输入框 |

## 常见问题

### 启动相关

**Q: 双击 exe 没反应？**
- 检查是否已有实例在运行（任务栏或系统托盘）
- 检查端口 13030 是否被占用
- 查看 `.data/studio.lock` 是否存在，手动删除后重试

**Q: 浏览器没有自动打开？**
- 手动访问 `http://127.0.0.1:13030`
- 检查防火墙是否阻止连接

**Q: 提示「密钥文件不存在」？**
- 确保根目录有 `Image_key.txt`
- 文件名不要包含空格或特殊字符
- 文件内容为纯文本密钥，不要有空行

### 生成相关

**Q: 提交后一直等待？**
- 检查网络连接
- 检查密钥是否有效和有余额
- 查看浏览器控制台是否有错误

**Q: 生成失败怎么办？**
- 查看错误提示（已脱敏，不会泄露密钥）
- 检查提示词是否包含敏感内容
- 尝试更换模型或简化提示词
- 失败不计费，可以重新提交

**Q: 可以同时生成多个吗？**
- 当前版本串行队列，一次只生成一个
- 可以提交多个，会自动排队

**Q: 超时警告是什么意思？**
- 请求超过 120 秒没响应
- 可能已经计费但图片未返回
- 建议检查服务商后台或重试

### 数据相关

**Q: 图片保存在哪里？**
- 桌面版：exe 同目录的 `outputs/` 文件夹
- 开发版：项目根目录的 `outputs/` 文件夹
- 按日期分类：`outputs/2026-01-10/` 这样的结构

**Q: 任务记录保存在哪里？**
- `.data/jobs/` 目录，每个任务一个 JSON 文件
- 删除任务会同时删除 JSON 和图片

**Q: 提示词片段保存在哪里？**
- 浏览器的 LocalStorage
- 清除浏览器数据会丢失
- 建议重要片段导出备份（可复制片段内容到文本文件）

**Q: 换设备后数据还在吗？**
- 任务记录和图片：跟着项目文件夹走
- 提示词片段和草稿：只在当前浏览器
- 桌面版可以拷贝整个文件夹到新设备

### 模型和参数

**Q: 有哪些模型可用？**
- 实时从服务商读取
- 当前已验证：`gpt-image-2.5-flare`
- 其它模型按服务商提供的选择

**Q: 模型选择有什么区别？**
- 不同模型风格、速度、费用可能不同
- 参考服务商文档
- 建议先用默认模型测试

**Q: 尺寸和质量怎么选？**
- 尺寸：方形适合头像、图标；横向适合横幅；竖向适合海报
- 质量：默认通常够用，高质量耗时更长
- 具体效果需实测

**Q: 可以生成多张吗？**
- 代码支持，默认限制 1 张/次
- 修改 `config/studio.json` 的 `maxImages` 调整
- 注意每张都计费

### 其它

**Q: 可以公网访问吗？**
- 当前版本只允许本机访问（127.0.0.1/localhost）
- 公网部署需修改同源检查逻辑
- 注意密钥安全

**Q: 支持多人使用吗？**
- 当前版本单用户设计
- 同目录同时只能启动一个实例
- 多人使用建议每人独立部署

**Q: 可以用其它服务商吗？**
- 需要服务商兼容 GPT Image API
- 修改 `Image_key.txt` 和 `config/studio.json` 的 `endpoint`
- 未实测其它服务商

**Q: 源码可以修改吗？**
- 完全开源，可以自由修改
- 修改后运行 `npm test` 和 `npm run check` 验证
- 建议先理解 `docs/architecture.md`
